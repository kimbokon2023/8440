# 알람 풍선 (Notification Bubble) - '오늘 하루 보지 않기' 기능 문서

## 1. 개요
`index2.php`의 대시보드 알림(예: 포미스톤 수주 알림)에 적용된 'x' 버튼 클릭 시 **오늘 하루 동안 알림을 숨기는 기능**에 대한 기술 문서입니다.

## 2. 동작 원리 (Logic)
이 기능은 **브라우저 쿠키(Cookie)**를 사용하여 구현되었습니다.
- 사용자가 'x' 버튼을 클릭하면 자바스크립트가 `hidePhomiReminder`라는 쿠키를 생성합니다.
- 이 쿠키의 만료 시간은 **오늘 밤 자정(23:59:59)**으로 설정됩니다.
- 페이지를 새로고침하거나 다시 방문할 때, PHP 코드가 이 쿠키의 존재 여부를 확인합니다.
- 쿠키가 존재하면 PHP 레벨에서 알림 HTML을 렌더링하지 않거나 `display: none` 상태로 처리합니다.

## 3. 구현 코드 (Implementation)

### 3.1 PHP (서버 사이드)
페이지 로드 시 쿠키를 확인하여 알림 표시 여부를 결정합니다.

```php
// index2.php

// 0. 쿠키 확인 (오늘 하루 안보기)
if (!isset($_COOKIE['hidePhomiReminder'])) {
    // 쿠키가 없을 때만 DB 조회 및 알림 표시 로직 수행
    
    // ... (관리자 여부 및 수주 내역 조회 로직) ...
    
    if (/* 조건 충족 시 */) {
        $phomi_reminder_display = 'block'; // 알림 표시
    }
}
```

### 3.2 JavaScript (클라이언트 사이드)
사용자가 닫기 버튼을 클릭했을 때 쿠키를 설정하는 함수입니다.

```javascript
// index2.php <script> 영역

function closePhomiReminder() {
    // 1. 알림창 숨김
    document.getElementById('phomiReminder').style.display = 'none';
    
    // 2. 오늘 하루 보지 않기 쿠키 설정
    var date = new Date();
    
    // 오늘 자정(23시 59분 59초)으로 만료 시간 설정
    date.setHours(23, 59, 59, 999); 
    
    var expires = "expires=" + date.toUTCString();
    
    // 쿠키 생성 (이름: hidePhomiReminder, 경로: /)
    document.cookie = "hidePhomiReminder=true; " + expires + "; path=/";
}
```

## 4. 참고 사항
- **쿠키 이름**: `hidePhomiReminder`
- **적용 범위**: 전체 사이트 (`path=/`)
- **초기화**: 다음 날 자정이 지나면 쿠키가 만료되어 삭제되므로, 알림이 다시 나타납니다.
- **테스트 방법**: 브라우저 개발자 도구(F12) > Application > Cookies 에서 `hidePhomiReminder` 쿠키를 삭제하면 즉시 다시 테스트할 수 있습니다.
